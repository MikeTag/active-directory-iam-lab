# 02 · Instalación de Windows Server

## Objetivo
Instalar Windows Server en DC01 con interfaz gráfica.

## Pasos
1. Iniciar la VM con la ISO y seguir el instalador.
2. Edición: **Standard Evaluation (Desktop Experience)**. La opción sin "Desktop Experience" no incluye interfaz gráfica.
3. Tipo de instalación: **Personalizada**, sobre el disco de 40 GB.
4. Definir la contraseña del Administrador (solo para el laboratorio; nunca se documenta ni se reutiliza).
5. Iniciar sesión. Para Ctrl+Alt+Supr dentro de la VM: Ctrl derecho + Supr.
